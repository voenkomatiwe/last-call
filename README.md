# Last Call ($LAST)

A memecoin with no keys and a daily game: the community has to hit a check-in goal every day. The last few people who close the goal enter a draw for the day's jackpot. If the community misses the goal, part of the shared pot burns.

> Work in progress for NEAR HACKATHON 2026 (memecoins, social).
